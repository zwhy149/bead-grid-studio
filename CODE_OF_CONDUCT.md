# Code of conduct

## Our standard

We want a technical community where people can report conversion failures, question design decisions, and disagree about trade-offs without harassment.

Expected behavior includes:

- using concrete evidence and reproducible examples;
- criticizing code or decisions rather than people;
- respecting privacy, copyright, identity, and accessibility needs;
- accepting correction and making room for contributors with different experience levels;
- avoiding sexualized language, personal attacks, threats, stalking, spam, and discriminatory conduct.

## Scope

This policy applies in repository Issues, pull requests, Discussions, code review, project chat, and public spaces where someone represents the project.

## Enforcement

Maintainers may edit or remove content, close participation, or ban accounts when behavior threatens people or prevents constructive collaboration. Enforcement decisions should be proportionate, documented privately when possible, and avoid publishing a reporter's personal information.

For urgent or sensitive GitHub-platform abuse, use GitHub's built-in private report-abuse tools. Non-sensitive project moderation requests may be raised in Discussions and labeled for maintainer attention. Do not open a public Issue containing private personal details.
