隐私说明

社区版 1.0.2 · 更新于 2026-08-16

社区版没有站内账号、支付、卡密、广告、行为分析或云端图片转换服务。

图片与图纸

你选择的图片在当前浏览器内解码、转换和导出，社区版不会把原图像素发送到项目服务器。自动恢复只保存图纸格子、色号、尺寸和显示设置，不包含参考原图。

工程文件

可编辑 JSON 包含工程标题、格子色号和设置，但不嵌入参考原图。分享前请检查工程标题，避免包含姓名、订单号或其他私人信息。

托管平台

当你访问 GitHub Pages 或其他托管者提供的演示站时，托管者可能按其隐私政策处理 IP、User-Agent、请求时间和安全日志。下载单 HTML 后离线打开不需要访问项目服务器。

你的控制

你可以在应用内清除自动恢复记录，也可以清除浏览器站点数据。浏览器本地存储可能因无痕模式、浏览器清理或设备故障消失，因此重要图纸应下载 JSON 工程备份。
