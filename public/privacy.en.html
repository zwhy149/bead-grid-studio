Privacy

Community Edition 1.1.1 · Updated 2026-08-17

Community Edition has no in-app account, payment, license-key gate, advertising, behavioral analytics, or cloud image conversion.

Images and patterns

Images you choose are decoded, converted, and exported in your current browser. Community Edition does not send source-image pixels to the project server. Draft recovery stores grid cells, color codes, dimensions, and view settings, but not the reference image.

Project files

An editable JSON project contains its title, cell color codes, and settings, but does not embed the reference image. Check the project title before sharing so it does not reveal a name, order number, or other private information.

Hosting providers

When you visit the GitHub Pages demo or another hosted copy, the hosting provider may process IP addresses, user agents, request times, and security logs under its own privacy policy. The portable single-HTML edition does not need the project server after you download it.

Your control

You can clear recovery data inside the app or clear the browser's site data. Local storage can disappear in private browsing, after browser cleanup, or because of device failure, so save important work as a JSON project backup.
