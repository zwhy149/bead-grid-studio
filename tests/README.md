# Test fixtures

`rocket-badge.svg` and its PNG rendering were created specifically for this repository and are licensed under Apache-2.0 with the rest of the project.

Future image fixtures must document their origin and redistribution permission. Prefer synthetic SVG/PNG images that isolate one property: transparency, a thin open line, disconnected components, extreme aspect ratio, white-background flood fill, or exact palette identity.

Do not commit customer photos, copyrighted characters, screenshots from shops/social media, or images that are merely “available online”.
