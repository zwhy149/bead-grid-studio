# Support

- Use **GitHub Discussions** for usage questions, pattern-making advice, and show-and-tell posts.
- Use the **Bug report** form for reproducible interface or export defects.
- Use the **Conversion quality** form for extra/missing beads, color mismatch, merged details, or background errors.
- Use **Private vulnerability reporting** for security issues.

This is a community project, so response times are not guaranteed. Keep an editable JSON copy of important work; browser local storage is not a backup service.
